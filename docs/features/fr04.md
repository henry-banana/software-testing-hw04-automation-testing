# FR-04 Hồ sơ cá nhân

Pool A, Web. Điểm xuất phát là SRS và bộ test FR-04 của HW02. Kiểm cập nhật họ tên, số điện thoại và địa chỉ, biên 9 đến 12 chữ số, tiền tố 0, email trên UI và lưu lại sau khi tải lại. Xác định case quyền truy cập nào tái hiện được trên Web và ghi giới hạn nếu cần phép kiểm tra API bổ sung. [SRS](https://github.com/ttbhanh/eshop-sut/blob/85af3ba875c88283615e22cb108f13e2fccaf0e9/README.md#fr-04-qu%E1%BA%A3n-l%C3%BD-h%E1%BB%93-s%C6%A1-c%C3%A1-nh%C3%A2n), [Case HW02](https://github.com/henry-banana/software-testing-hw02-domain-testing/blob/main/tests/A-FR04-profile.md)

- Dữ liệu ở `data/fr04.json`
- Script ở `tests/fr04/profile.spec.ts`
