# FR-17 Quản lý mã giảm giá

Pool C, Web Admin. Đặc tả và phạm vi HW02 gồm Thêm, Xem, Xóa. Ưu tiên required fields, mã duy nhất, loại fixed hoặc percent, biên của số tiền giảm, giá trị đơn tối thiểu, giới hạn lượt dùng, xác nhận danh sách và quyền quản trị. Dùng mã riêng cho dữ liệu có thay đổi và chuẩn bị cleanup. [SRS](https://github.com/ttbhanh/eshop-sut/blob/85af3ba875c88283615e22cb108f13e2fccaf0e9/README.md), [Case HW02](https://github.com/henry-banana/software-testing-hw02-domain-testing/blob/main/tests/C-FR17-coupon-management.md)

- Dữ liệu ở `data/fr17.json`
- Script ở `tests/fr17/manage-coupons.spec.ts`

## Phân tích điều kiện và thiết kế

| Điều kiện | Tách dữ liệu và cách quan sát |
| --- | --- |
| Tạo, xem và xóa | Tạo mã fixed và percent. Khi xem, đối chiếu đủ dữ liệu trong dòng theo mã. Khi xóa, kiểm mã biến mất trên UI và API. |
| Mã duy nhất | FR17-03 chuẩn bị bản ghi khác giá trị giảm rồi đưa mã trùng. Kiểm chỉ còn bản ghi cũ với đúng giá trị. |
| Trường bắt buộc | Kiểm mã, giá trị giảm, hạn, ngưỡng và giới hạn lượt. Trường rỗng trong form có thể thành chuỗi rỗng trong request. Giữ biến thể đó riêng với payload bỏ thuộc tính ở HW02. |
| Miền số | Thử giá trị giảm âm, 0 và dương, ngưỡng âm hoặc 0, giới hạn 0, 1 và 2 trên các case phù hợp. Đọc lại bản ghi để phân biệt báo thành công với dữ liệu thật. |
| Vai trò | FR17-13 đăng nhập màn Admin bằng account thường. Nó kiểm cổng Web và được truy vết tới FR-12. |

Ba hồ sơ lỗi tương ứng với giá trị giảm, ngưỡng đơn và giới hạn lượt. [HW04-C01](../../bugs/FR17-C01.md), [HW04-C02](../../bugs/FR17-C02.md), [HW04-C03](../../bugs/FR17-C03.md)
