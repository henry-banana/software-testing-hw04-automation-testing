# Báo cáo chạy Playwright

Mỗi lượt chạy sinh `reports/<batch>/<feature>/<browser>/html/index.html` và `results.json` trong thư mục của trình duyệt. `batch` là thời điểm bắt đầu đợt chạy theo UTC. Giữ nguyên toàn bộ thư mục HTML và các tệp đính kèm khi đưa đợt chạy chính thức lên GitHub và vào ZIP.
